RPG2LX - Your game library

Copy each complete RPG Maker MV game into its own folder here:

games/My Game/data/System.json
games/My Game/img/...
games/My Game/audio/...
games/My Game/js/...

Desktop exports inside games/My Game/www/ are also detected.
Do not copy only the EXE: include all game data and assets.

RPG2LX currently provides a menu, data inspection and experimental native
map exploration. Press X / P in game details to try it. Compatibility is
partial: battles, audio, saving and JavaScript plugins are not implemented.

Save data and settings belong to RPG2LX's saves/ and config/ folders.
Do not include commercial game files when distributing this package.

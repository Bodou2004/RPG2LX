# Datos del recorrido de prueba de Project1

Esta carpeta conserva los siete archivos de datos preparados por Antigravity y revisados/guardados por Codex en RPG Maker MV. Es una actualización para un proyecto MV estándar, no un juego completo: no incluye imágenes, música, fuentes, plugins, el editor ni el motor JavaScript de RPG Maker.

Para reconstruir el proyecto de prueba:

1. Crear un proyecto estándar de RPG Maker MV con una instalación propia del editor, conservando sus cuatro actores y recursos predeterminados.
2. Respaldar su carpeta data y copiar allí estos siete JSON. Conservar el resto de la base de datos y los recursos del proyecto recién creado.
3. Abrir el proyecto en RPG Maker MV, revisar y guardar. El inicio queda en Map001 (8,6); título Castle, cuatro miembros y seguidores activos.
4. Copiar el proyecto completo a games/Project1/ de RPG2LX. En consola elegir Nueva partida.

El guía está al norte del inicio. Cofre al oeste, armería al este, maestro al sur, palanca al suroeste y portal más al este. La guía detallada y el alcance están en [TEST_PROJECT.md](../../docs/TEST_PROJECT.md).

Estos datos se probaron mediante el recorrido [project1_features.json](../../tests/scenarios/project1_features.json), de 95 pasos, sobre el proyecto completo local. Una base de datos inicial distinta puede tener otros IDs o recursos: revisar sus referencias antes de usar el recorrido.

Los recursos de RPG Maker deben obtenerse de una copia autorizada y usarse conforme a sus [términos oficiales](https://rpgmakerofficial.com/en/support/rule/). No se otorga una licencia sobre recursos de terceros desde este repositorio. Los archivos del juego original, sus partidas y los recursos comerciales permanecen fuera del historial Git.
